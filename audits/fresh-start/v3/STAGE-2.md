## What the reconciliation now checks

Each row uses its own counted time, falling back to the area's end time. All movements inside that sheet's window or within 30 minutes of the row time require owner before/after classification. A lot spread across areas additionally requires review of movements between the earliest and latest observations and explicit allocation of each signed movement among affected count rows. FL has no location balances: the tool shows whole-lot FL references at the individual times and combines the physical observations only after that review.

Moves are caught by the tool only when logged, tagged, or noted; for anything else, the H1 multi-area hold is the control. Every lot observed in more than one area has one hold listing all its rows, `owner confirms no unlogged moves between rows R1/R2`, until the owner confirms the bound `multi_area_reviews` entry. A tag or note is evidence for office review; it does not prove that every move was recorded.

Late-entry clause 1 applies when entry time is on/after count start and entry minus occurred time exceeds 15 minutes, even if the occurrence preceded count start. Clause 2 covers entries typed after sheet end whose occurred time is at or before sheet end plus the maximum of the existing margin, 30 minutes, and half the sheet duration. Logged changed/voided events, post-count corrections and moves require review. Duplicate marking uses only the count sheet's `duplicate` tick column (see the transcriber guide); note text and repeated tags do not select duplicate rows. At least one row survives each duplicate group, with a hold if all were selected for exclusion. A moved pallet counted at both ends is removed from the sum once; one counted at neither end is added once, only with owner-confirmed endpoints and inclusion facts. A move-log row whose destination is a consumed lot stays held across reruns until that row is removed from the move log; retain consumption evidence in the ordinary ledger review. Fingerprints prevent old answers from silently approving changed evidence.

Invalid or blank-product observations stay in their own sheet's follow-up list. Certified coverage without count rows gets a per-product owner review. Prior v3 openings with any count hash require journal proof. Generate the CSV template with the duplicate tick column using the command in [the transcriber guide](../tool-guide.md); the original issued packet remains preserved.

Ingredient, batch and finished lots use the same reset review controls. Packaging observations remain in a separate information-only report with units as entered. Their missing counts, lots and unresolved movements never generate reset holds or changes. Pallets 102 and Pallet Charge 176 are excluded billing items. Apply rejects old v3 scope-policy previews and excluded rows; current catalog exclusions are rechecked before posting. Estimates carry into the proposed adjustment reason. Unidentified reset-scope items have a seven-day follow-up and no lot-creation path. Sunshine pouch changes require the office's ownership evidence; customer-owned or unresolved stock stays held for supported treatment.

Per-row comparisons are retained in the signed preview. There is one proposed adjustment per existing lot, dated at the latest observation for that lot and calculated using every underlying row cutoff. This avoids repeatedly resetting the entire FL lot for separate shelf counts. All later movement is carried forward once. Verification can independently prove the executor's prior posts from the signed preview, journal chain and exact ledger events without importing the write-capable executor.
