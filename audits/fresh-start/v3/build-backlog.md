# FL build backlog - not built

**Plain-English summary:** The count and local reconciliation tools are prepared now. The changes below would make daily FL records more dependable; none has been built, migrated or deployed in this task. Estimates are engineering days including meaningful tests and review, before owner acceptance and rollout. They are planning ranges, not commitments. Production building still waits for PR #67 and the rollout housekeeping work specified earlier.

| Proposed change | What the owner would see / why | Estimated size |
| --- | --- | --- |
| Deduct packaging on pack | Consume the actual bags, boxes, tape, cases and labels used by each pack, with configured packaging quantities/units, confirmed lots, explicit waste and named actor. Make reversals/corrections restore the right quantities and prevent duplicate consumption. Until this exists and the owner approves a later count, keep packaging counts information only and excluded from resets. Pallets 102 and Pallet Charge 176 remain billing items, not packaging consumption stock. | Medium–large, 5–8 days |
| Storage locations | A maintained area/bin list and auditable lot transfers between locations; balances separately by item, lot and location. Migrate unknown locations explicitly and prevent duplicate movement effects. | Large, 8–12 days |
| Sunshine-owned stock stored at CNS | Show physical custody separately from ownership and available-to-sell stock. Link ownership changes to approved invoice/order evidence without pretending stock physically departed. Preserve splits, returns and credits. | Large, 7–12 days |
| Flag instead of block on short packs/makes | Record actual work and an explicit shortfall with product/lot, quantity, actor and originating event. An owner queue resolves it through a count or missing movement; do not fabricate makes/receipts. Keep physical allocation and negative-stock exceptions visible. | Medium–large, 5–8 days |
| Actual-lot confirmation at staging | For pallet items, capture the actual lot when the pallet moves to production. For case items, require typing the last four characters of the actual lot, with no prefilled default; ambiguous suffixes require the full code or scan. Link confirmation to consumption and retain actor/time. | Medium–large, 5–8 days |
| Bulk bin IDs and tare weights | Durable bin identity, verified empty tare, gross/net weighed amounts, scale/time/actor and an Estimated distinction. Preserve tare changes; avoid treating container tokens as pounds. | Medium, 3–5 days |
| Weighed bulk transfer to Sunshine triggers invoice | Link a confirmed weighed bulk dispatch (lots, bins, net lb, time and actor) to a reviewable invoice trigger with agreed price and duplicate prevention. This reflects the latest requested backlog direction; before build, owner confirms how later Sunshine yield reports and credits alter that invoice. | Large, 6–10 days |
| Order cannot close without shipment | Require posted shipment coverage before normal closure, with an explicit owner-reviewed exception path for genuine non-shipment closure reasons. Reconcile legacy status/state disagreement and partial/cancelled/credited orders. | Medium, 3–5 days |
| Correction reasons and photo for changes over 500 lb | Require a specific correction reason and named actor; require supporting photo/document for absolute weight changes over 500 lb. Keep units clear for count-based supplies and immutable links to the original event. | Medium, 3–5 days |
| Owner weekly view | A concise view of open shortfalls, overdue unidentified lots, large corrections, late-entered movements, recount results, aged stock/holds and unshipped orders, with named owners and dates. | Medium, 4–6 days |

Build order proposal: locations and bin identity first; staging/shortfalls next; ownership and invoice/order rules once the owner confirms the commercial process; weekly view after exception definitions settle. Some shared foundations overlap, so do not simply add every range as a project quote. Each change needs its own reviewed implementation plan, migration numbering confirmed against then-current main, and rollout evidence.
